## NASA Sources and References

The following NASA resources were consulted as references for the Mars Explorer 3D project:

1. **NASA Mars Trek** – Mars mapping and geographic data.  
   https://trek.nasa.gov/mars/

2. **NASA HiRISE (High Resolution Imaging Science Experiment)** – High-resolution images of the Martian surface.  
   https://hirise.lpl.arizona.edu/

3. **NASA Mars Trek API Documentation** – Mapping services and Mars data layers.  
   https://trek.nasa.gov/tiles/apidoc/trekAPI.html?body=mars

4. **NASA Planetary Data System (PDS)** – Scientific data and planetary exploration archives.  
   https://pds.nasa.gov/

5. **NASA Mars 2020 Mission** – Information about the Perseverance rover and the Ingenuity helicopter.  
   https://mars.nasa.gov/mars2020/

6. **NASA Mars Exploration** – Scientific information about Mars, its geology, climate, and exploration.  
   https://science.nasa.gov/mars/

7. **NASA Open APIs** – Access to NASA's public data and application programming interfaces.  
   https://api.nasa.gov/

8. **NASA Mars Data Catalog (IPDA)** – Access to planetary datasets and Mars exploration resources.  
   https://ipda.pds.mcp.nasa.gov/access-to-data/mars-data/

*These resources served as scientific and visual references for the project's Martian environment, surface mapping, terrain representation, and rover exploration features.*
