## 🚀 About the Project

Mars is a hostile environment: rugged terrain, an extremely thin atmosphere, dust storms, large temperature swings, and communication delays with Earth. Every mission, robotic or crewed, depends on **good decisions about where to land, where to travel, and what to avoid**.

**Mars Explorer** brings open NASA data into a single, easy-to-use visual application that works as a **"survival guide"**: it displays the terrain, highlights safe and risky zones, and helps users plot exploration routes.
